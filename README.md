# Сокровища Земли под охраной человека

Интерактивное путешествие с 3D-графикой, управляемое прокруткой. Урок для 4 класса на 23 минуты.

## Сайт

https://polygalovartur22-create.github.io/earth-treasures-3d/

Режим ведущего: добавьте `?presenter=1` к адресу сайта. Заметки держите на отдельном экране в режиме «Расширить».

## Публикация

GitHub Pages публикует папку `docs` из ветки `main`. Все ресурсы хранятся в репозитории; сборка не требуется.

## Управление

- Прокрутка перемещает камеру между сценами.
- Во время чтения текста удерживается подходящий ракурс.
- Пауза движения останавливает фоновые анимации.
- Лёгкий режим снижает нагрузку.
- Викторина объясняет ответы.

Графика: Three.js (MIT).
